# Scenarios: core-v1

Source of truth: `scenarios/core-v1/*.yaml` (schema in `packages/shared/src/scenario.ts`). Money in YAML is USD with up to two decimals and is converted to integer cents on load.

The **saboteur** column lists the assertions the scripted saboteur (`apps/server/src/oracles/sNN.ts`, later task) must fail, and only those. The oracle must pass every assertion.
